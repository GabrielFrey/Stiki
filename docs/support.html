English

Stiki does not use accounts. If something fails, the steps below usually fix it. For a human reply, open an issue on the Stiki GitHub repository or replace this paragraph with an email address before you ship.

Make a sticker

  1. Open the Create tab and pick a photo (or use the camera).
  2. Choose a subject, refine the cutout if needed, then edit outline, text, or filters.
  3. Save to the library. Re-open any sticker to change the recipe; the original stays on disk.

Export a pack

Open Packs, select a pack, and check the readiness badges. Use Auto-fit if a destination is over limit. iMessage reads the App Group catalog. Other messengers receive files or pasteboard data you trigger yourself.

Stiki Pro and Restore

Open Settings → Upgrade to Pro, or the paywall from a locked feature. Buy the one-time product or the yearly subscription. There is no login and no trial. If you already paid on this Apple ID, tap Restore purchases. Manage a yearly subscription in Settings → Apple ID → Subscriptions (or Manage subscription on the paywall).

Sandbox / TestFlight: use a Sandbox Apple ID. Reviewers: see docs/appstore/REVIEW_NOTES.md in the repository — no demo account is required.

iCloud sync

Pro only, off by default. Turn it on in Settings, then restart Stiki so the CloudKit container can rebuild. Sign in to iCloud on the device first.

iMessage stickers missing

The app and the Messages extension share group.com.stiki.shared. If Settings warns that the App Group is missing, the build is not signed with that group. Re-export after the group is on both App IDs.

Privacy

Read the Privacy Policy. Data is processed on device. We do not run an account server.

Русский

В Stiki нет аккаунтов. Если что-то сломалось, начните с шагов ниже. Для ответа человека откройте issue в репозитории или укажите email до публикации.

Стикер

Вкладка «Создать» → фото или камера → вырезать объект → сохранить. Стикер можно открыть снова: исходник остаётся на диске.

Экспорт пака

Паки → значки готовности → автоподгонка при превышении лимита. iMessage читает каталог App Group.

Pro и восстановление

Настройки → «Перейти на Pro». Разовая покупка или годовая подписка. Входа нет. «Восстановить покупки», если уже оплачено на этом Apple ID. Подписку отменяют в Настройки → Apple ID → Подписки.

iCloud

Только Pro, выключено по умолчанию. Включите и перезапустите Stiki.

עברית

אין חשבון ב־Stiki. אם משהו נכשל, התחילו בצעדים כאן. לפני הפרסום החליפו את הפנייה ב־issue או באימייל קבוע.

יצירת מדבקה

לשונית היצירה → תמונה או מצלמה → חיתוך → שמירה. אפשר לפתוח שוב לעריכה; המקור נשאר בדיסק.

ייצוא חבילה

חבילות → תגי מוכנות → התאמה אוטומטית אם חורגים מהמגבלה. iMessage קורא את קטלוג ה־App Group.

Pro ושחזור

הגדרות → שדרוג ל־Pro. רכישה חד-פעמית או מנוי שנתי. אין התחברות. שחזור רכישות אם כבר שילמתם ב־Apple ID הזה. ניהול מנוי: הגדרות ← Apple ID ← מנויים.

iCloud

רק ב־Pro, כבוי כברירת מחדל. הפעילו והפעילו מחדש את Stiki.
